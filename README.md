# Nitin Kumar Singh — Portfolio Website

## Files
- `index.html` — responsive portfolio website
- `profile.png` — professional profile photo
- `Nitin-Kumar-Singh-Resume.pdf` — downloadable resume

## Preview locally
Keep all three files in the same folder and open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `nitin-portfolio`).
2. Upload all three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Your site should appear at a URL like `https://nitinsingh0820.github.io/nitin-portfolio/` after deployment.
